# 입시 전형 데이터

원서 화면의 '목록에서 고르기'(대학 → 전형 → 학과)가 읽는 파일. 학년도마다 `<학년도>.json` 하나.
앱을 열 때가 아니라 원서 창을 열 때만 불러와서 앱 속도에는 영향이 없음.

**원본(대학 모집요강 등)에서 옮긴 값만 넣고, `sources`에 출처를 남길 것.**

```jsonc
{
  "year": 2028,
  "updated": "2026-11-23",
  "sources": [{"univ": "연세대학교", "doc": "2028학년도 수시모집요강", "url": "https://…"}],
  "univs": [
    {
      "n": "연세대학교",            // 대학 이름 (원서에 들어가는 이름)
      "g": "서울",                 // 묶음: 서울 / 과학기술원 / 수도권 의대 …
      "types": [
        {
          "n": "추천형",                       // 전형 이름
          "cat": "학생부교과",                  // 학생부교과 · 학생부종합 · 논술 · 실기/실적 · 정시(가/나/다군) …
          "doc": "2027-09-15",                 // 서류 마감 (없으면 생략)
          "itv": "2027-11-28",                 // 면접일 (없으면 생략)
          "r1": "2027-11-20",                  // 1단계(1차) 합격자 발표 (단계별 전형만)
          "res": "2027-12-17",                 // 최종(최초) 합격자 발표
          "min": {"n": 3, "k": 4, "subs": ["kor","math","eng","sci"], "sci": "best", "hist": 4},
                                               // 수능 최저: 과목 n개 합 k 이내. sci: best(탐구 상위 1) / avg(2과목 평균 버림) / avgx(2과목 평균 그대로). 없으면 null
          "minText": "…",                      // 최저 원문 요약. min으로 표현 못 하면 min:null + minText → 메모에 원문이 들어감
          "note": "수학 미적분·기하 중 1, 과탐 필수", // 앱 계산에 안 들어가는 조건은 글로 (메모에 들어감)
          "majors": [
            {"n": "의예과", "cnt": 22},
            {"n": "치의예과", "cnt": 10, "itv": "2027-11-29", "min": null}   // 학과마다 다르면 덮어씀
          ]
        }
      ]
    }
  ]
}
```
