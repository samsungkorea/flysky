# Fly Sky 정리

대입 준비용 개인 웹사이트. 저장소: `samsungkorea/flysky`

- `index.html`: 사이트 전체
- `ypt-relay/`: 열품타 중계 서버 (Cloudflare Worker)

---

## 1. 기능 목록

| 기능 | 상태 |
|---|---|
| 타이머 · 스톱워치 | 완료 |
| 수능 타이머 (수능 시간표대로 흐르는 시계) | 완료 |
| 수시 준비 (원서 보드, 최저 계산기) | 완료 |
| 면접 준비 | 외부 링크로 연결 (`samsungkorea.github.io/yonsei-medical`) |
| 열품타 연동 | 완료 (중계 서버 배포 필요) |
| D-day · 목표 대학 | 완료 |
| 버킷리스트 (수능 끝나고 할 것) | 완료 |
| 캘린더 + Google 캘린더 연동 | 완료 (클라이언트 ID 설정 필요) |
| Google 로그인 | 완료 (클라이언트 ID 설정 필요) |

## 2. 구조

탭을 고정하지 않고, 기능을 계속 붙일 수 있는 구조로 감.

- **사이드바 (항상 고정)**: 홈 · 타이머 · 입시 · 캘린더 · 면접(외부 링크) · 모든 기능 · 계정
  - 폰에서는 화면 아래 메뉴바로 바뀜
- **홈**: D-day, 오늘 일정, 다음 면접, 공부 시간, 버킷리스트, 열품타 그룹
  - 위쪽 칩(공부 / 입시 / 면접 / 일정)으로 카드 필터
- **모든 기능**: 카테고리별 바로가기. 새 기능은 여기에 추가
- 로그인은 Google 계정 기반

- 검정 카드는 한 화면에 하나만

- 화면 확대·축소 막음

## 4. 화면별 내용

### 타이머
- **수능 모드**: Figma '수능 시계' 디자인을 SVG로 다시 그림. 시침·분침·초침이 실제로 움직임 (초침은 1초마다 끊어서)
  - 실제 시각 / 모의 수능(시작 교시를 골라 그 시각부터 흐름) 전환
  - 현재 교시, 남은 시간, 다음 교시, 시간표 표시
  - 알림음: 교시 시작 · 종료 10분 전 · 종료
  - 화면 꺼짐 방지
  - **전체화면**: 시계만 크게 표시 (X 버튼 또는 Esc로 나가기)
- **스톱워치**: 과목 선택, 랩 기록
- **타이머**: 과목별 시험 시간 바로 선택, ±1·5·10분 조절

수능 시간표 (기억 기준, 공식 시간표와 대조 필요):

| 교시 | 과목 | 시간 |
|---|---|---|
| 1 | 국어 | 08:40 – 10:00 |
| 2 | 수학 | 10:30 – 12:10 |
| – | 점심 | 12:10 – 13:10 |
| 3 | 영어 | 13:10 – 14:20 |
| 4 | 한국사 | 14:50 – 15:20 |
| 4 | 탐구 1선택 | 15:35 – 16:05 |
| 4 | 탐구 2선택 | 16:07 – 16:37 |
| 5 | 제2외국어/한문 | 17:05 – 17:45 |

### 입시
- **수시 원서**: 6칸. 대학, 학과, 전형, 상태, 서류 마감, 면접일, 수능 최저, 메모
- **최저 계산기**: 등급 입력 → 원서별 충족 / 몇 등급 부족 표시
  - 최저 설정: n과목 합 k, 반영 과목, 탐구(상위 1과목 / 2과목 평균 버림), 한국사 조건
- **D-day · 목표 대학**: 별표 단 D-day가 홈에 표시됨. 목표 대학 순서 변경 가능

### 캘린더
- 월간 달력에 내 일정 · D-day · 원서 마감 · 면접을 색 점으로 함께 표시
- 날짜를 누르면 그날 목록, 거기서 일정 추가

### 버킷리스트
- 체크 기능 없음 (수능 전에 하는 게 아니라서). 적어 두기만 함
- 여행 · 배우기 · 먹기 · 쉬기 · 기타 카드로 나눔

## 5. 열품타 연동

- 공식 API는 없음. 앱이 쓰는 서버(`https://pi.tgclab.com`)를 직접 호출
  - 요청 형식 참고: `deveworld/ypt_client`, `huneyoliv/desky`
  - 로그인 `POST /user/sign-in-jwt` (이메일·비밀번호 → JWT), 이후 헤더 `Authorization: JWT <token>`
  - 내 정보 `POST /user/v2/reload/info`, 그룹 `GET /group/groups/v2`, 그룹 멤버 `GET /logs/group/members/v2`
  - 기록 `POST /study/start` (과목 이름), `POST /study/stop` (시작 시각)
- 브라우저에서 바로 부르면 CORS에 막혀서 중계 서버(`ypt-relay/worker.js`)를 거침
  - 허용한 사이트 주소에서 온 요청만 받고, 위 경로만 통과시킴
  - 비밀번호·토큰은 저장하거나 기록하지 않음
- 사이트에서 하는 일
  - 홈 '오늘 공부 시간': 열품타 오늘 공부 시간 + 과목별 막대 (상위 4과목)
  - 홈 '열품타 그룹': 내 그룹 멤버 순위 · 공부 중 여부. 지금 공부 중인 사람은 진한 테두리로 강조, 쉬는 사람은 흐리게
    - 공부 중 판정은 멤버 데이터의 `dl.is`(일시정지는 `dl.ia`) 기준
    - 그룹이 여러 개면 위 버튼으로 전환. 버튼 순서는 연동 관리 화면에서 ↑↓로 바꿀 수 있음
  - 홈 '오늘 공부 시간'의 재생 버튼으로 열품타 기록 시작/정지. 아래 칩에서 열품타 과목을 고름 (기록 중엔 못 바꿈)
  - 타이머 · 스톱워치는 열품타와 상관없이 따로 동작
  - 1분마다 그룹, 5분마다 전체 새로고침
- 비밀번호는 저장하지 않음. JWT 토큰만 브라우저(localStorage)에 저장
- 로그인 방법 두 가지
  - **이메일**: 열품타 이메일·비밀번호로 로그인
  - **구글**: Fly Sky에 구글로 로그인했으면, 연동 화면의 '구글 계정으로 열품타 연결' 버튼으로 바로 됨
    - 원리: 구글 사용자 ID(`sub`)를 열품타에 `g<sub>`로 보냄. `POST /user/social/sign-up-jwt`
    - 열품타를 **같은 구글 계정으로 가입**했을 때만 됨. 안 되면 "이 구글 계정으로 가입된 열품타가 없어요"가 뜸
    - 카카오·네이버는 웹에서 안 됨 (앱 전용 리다이렉트 + 앱마다 사용자 ID가 달라서). 이 경우 열품타 앱에서 이메일·비밀번호를 추가로 설정하면 이메일 로그인으로 됨
- 주의: 약관과 충돌할 수 있고, 열품타 쪽 변경으로 언제든 깨질 수 있음. 특히 구글 연결은 실험적이라 열품타가 막으면 안 될 수 있음. 스크린샷 / 직접 입력 탭은 아직 화면만 있음

### 중계 서버 배포 (Cloudflare Worker, 무료)

1. https://dash.cloudflare.com 가입
2. **Workers & Pages → Create → Worker** → 이름 `flysky-ypt` → Deploy
3. **Edit code**에서 `ypt-relay/worker.js` 내용을 통째로 붙여 넣고 Deploy
4. **Settings → Variables**에 `ALLOWED_ORIGINS` = `https://samsungkorea.github.io` (안 넣어도 기본값이 이 주소)
5. 나온 주소(`https://flysky-ypt.<계정>.workers.dev`)를
   - 사이트의 열품타 연동 화면 '중계 서버 주소'에 넣거나
   - `index.html`의 `YPT_RELAY_URL`에 넣어 두면 입력칸이 사라짐

명령줄로 하려면 `ypt-relay` 폴더에서 `npx wrangler deploy`.

## 6. Google 로그인 · 캘린더 설정

코드 맨 위 `GOOGLE_CLIENT_ID`에 값을 넣어야 동작함. 로그인 한 번으로 계정 정보와 캘린더 권한을 같이 받음.

1. Google Cloud Console에서 프로젝트 만들고 Calendar API 사용 설정
2. OAuth 동의 화면 → 테스트 사용자에 내 Gmail 추가
3. OAuth 클라이언트 ID(웹 애플리케이션) 만들기
4. 승인된 JavaScript 원본에 `https://samsungkorea.github.io` 등록
5. `index.html`의 `GOOGLE_CLIENT_ID`에 ID 넣기

- ID를 넣으면 처음 열 때 로그인 화면이 뜸. '로그인 없이 계속'을 누르면 그 기기에서는 다시 묻지 않음
- 로그인 정보(이름 · 이메일 · 사진)만 저장. 캘린더 토큰은 1시간 뒤 만료되고, 필요할 때 다시 받음

파일을 직접 여는 방식(file://)에서는 동작하지 않음.

### 일정이 저장되는 곳
- **Google로 로그인한 상태**: 일정의 원본은 **Google 캘린더(기본 캘린더)**. 추가·수정·삭제가 전부 Google에 바로 반영되고, 어느 브라우저·기기에서 열어도 같은 일정이 보임
  - 캘린더 화면에 들어가면 자동으로 불러옴 (토큰이 없으면 잠깐 Google 팝업이 떴다 닫힘)
  - 마지막으로 불러온 일정은 브라우저에 임시 저장해 둬서, 새로고침해도 홈 '오늘 일정'에 바로 보임
  - 예전에 이 기기에만 저장한 일정이 있으면 캘린더 화면 아래 '옮기기'로 Google에 올릴 수 있음
- **로그인 없이 쓰는 경우**: 일정은 그 브라우저에만 저장 (기기끼리 동기화 안 됨)
- D-day · 원서 · 목표 대학 · 성적 · 버킷리스트는 아직 브라우저에만 저장됨

## 8. 알아 둘 것

- **예시 데이터**: 원서, 최저 기준, 성적, 일정, 버킷리스트, 열품타 그룹은 화면을 보여 주려고 지어낸 값. 실제 대학 최저 기준과 다를 수 있음
- **확인 안 한 날짜**: 수능일(2026.11.19), 수능 성적 발표(12/4)
- **데이터 저장**: 브라우저(localStorage)에 저장됨. 기기끼리 동기화 안 됨
- **확대 막기**: 아이폰 사파리에서 '손쉬운 사용' 확대를 켜 두면 완전히 막지 못할 수 있음 (실기기 미확인)
