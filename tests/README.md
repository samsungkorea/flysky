# 열품타 동기화 테스트 (Playwright)

가짜 열품타 서버로 Fly Sky를 돌려 보는 테스트. `node tests/<파일>` 로 실행.

- `ypt-fuzz.js` — 랜덤 테스트. 서버가 응답마다 최신 상태(45%) 또는 5~60초 전 사본을 섞어 보내고,
  열품타 앱 시작/정지 · Fly 버튼 · 앱 다시 열기를 무작위로 함. 항상 지켜야 할 규칙을 검사:
  실제 상태가 40초 넘게 그대로인데 Fly가 다르게 보이면 실패 / 누르지 않았는데 시작·정지 요청이 가면 실패 /
  오늘 공부 시간이 설명 없이 줄면 실패. `node tests/ypt-fuzz.js [실행 수] [초] [시드,..]`
- `ypt-suite.js` — T1–T12 정해진 상황 테스트
- `ypt-guard.js` — G1–G5 '내가 끄기 전엔 절대 멈추지 않음' 테스트
- `ypt-ck5.js` — 실제로 난 버그 재현: 정지 후 그룹 목록이 정지 전 사본을 계속 보냄 → 다시 열어도 꺼진 채여야 함
